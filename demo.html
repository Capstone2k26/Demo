01 / The basics

Git is not GitHub.

They work brilliantly together, but they solve different parts of the same problem.

⌘

Git / the tool

A version control system that runs on your computer. Git records changes as snapshots so you can review, compare, and restore your work.

works locally · open source
◉

GitHub / the platform

A place to host Git repositories online. GitHub adds collaboration tools like pull requests, issues, project boards, and code review.

hosts projects · connects people
02 / The everyday loop

From change to collaboration.

Most Git workflows follow a simple cycle. Make a change, save a snapshot, then share it.

STEP 01

Make changes

Edit files in your project and try things out.

working directory
STEP 02

Stage a snapshot

Choose which changes belong in your next save.

git add .
STEP 03

Commit locally

Record a named checkpoint in your history.

git commit -m "Add feature"
STEP 04

Share on GitHub

Push your commits so others can see and review.

git push

04 / GitHub vocabulary

Tools for working in the open.

These building blocks help turn a repository into a shared workspace.

⑂

Branch

An independent line of work. Build a feature without changing the main version until you are ready.

⇄

Pull request

A proposal to merge changes. Teammates can discuss, review, and improve the code together.

#

Issue

A place to track a bug, question, or idea and coordinate what should happen next.
